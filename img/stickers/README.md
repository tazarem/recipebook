# 일기 꾸미기 스티커 그림

식사 일기에 도장처럼 찍는 꾸미기 스티커입니다. (맛 평가와는 상관없음)

지금 들어 있는 20장(밥공기, 계란후라이, 삼각김밥, 딸기, 머그컵, 하트, 별, 고양이, 강아지, 토끼, 곰, 병아리, 토스트, 사과, 버섯, 해골, 불꽃, 음표, 얼음, 따봉)은
이 앱을 위해 직접 찍은 그림이고, 원본은 `draw.py`의 글자 격자입니다.
`sticker_count`를 0으로 두면 그림 대신 기본 이모지 스티커를 보여 줍니다.

## 파일

- 이름: `sticker_1.png`, `sticker_2.png`, `sticker_3.png` … 번호를 **1부터 빠짐없이** 붙입니다.
- 몇 장이든 됩니다. 장수를 `config.js`의 `sticker_count`에 적으면 그만큼 불러옵니다.

## 규격

- 캔버스는 정사각형 **8 × 8**, **16 × 16**, **32 × 32 px** 중 아무거나 (섞어 써도 됨)
  - 작게 그릴수록 도트 하나하나가 크게 보입니다.
- **PNG**, 배경 투명
- 내보낼 때 **100%(1배)** 그대로 (확대해서 내보내지 않기)
- 앱이 `image-rendering: pixelated`로 정수배로만 키워서 보여 주므로 도트가 뭉개지지 않습니다.

| 보이는 곳 | 크기 | 8×8 | 16×16 | 32×32 |
|---|---|---|---|---|
| 식단 목록의 작은 표시 | 32 × 32 | 4배 | 2배 | 1배 |
| 일기 화면, 고르는 창 | 64 × 64 | 8배 | 4배 | 2배 |

- 밝은 테마와 어두운 테마(크립틱) 양쪽에 올라가므로 **어두운 외곽선**을 두르면 둘 다 잘 보입니다.
- 일기에 붙인 스티커는 네 가지 기울기 중 하나로 살짝 돌아가서 보입니다.

## 적용

1. 이 폴더에 `sticker_1.png` ~ `sticker_N.png`를 넣는다.
2. `config.js`의 `sticker_count`를 N으로 바꾼다. (0이면 기본 이모지)
3. `service-worker.js`의 미리 받는 목록(STATIC_CACHE_LIST)에도 새 파일을 추가한다. (오프라인에서 바로 보이게)
4. `service-worker.js`의 캐시 이름과 `config.js`의 버전을 올리고 배포한다.

## 주의

- 일기에는 "몇 번 스티커를 찍었는지"가 저장됩니다. 나중에 **번호의 그림을 바꾸면** 그 번호를 찍어 둔 옛 일기의 그림도 같이 바뀝니다. 새 그림은 뒤 번호로 추가하는 것이 안전합니다.
- 이모지로 찍어 둔 옛 일기는 그림으로 바꾼 뒤에도 이모지 그대로 보입니다.
