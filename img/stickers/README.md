# 맛 평가 스티커 그림

식사 일기의 맛 평가 스티커를 이모지 대신 직접 그린 그림으로 바꿀 때 이 폴더에 넣습니다.

## 파일 (4장, 이름 고정)

| 파일 | 뜻 |
|---|---|
| `yum.png` | 맛있었당~ |
| `good.png` | 괜찮았어 |
| `soso.png` | 그냥 그래 |
| `bad.png` | 별로.. |

## 규격

- 캔버스 **32 × 32 px**, 정사각형
- **PNG**, 배경 투명
- 내보낼 때 **100%(1배)** 그대로 (확대해서 내보내지 않기)
- 앱이 `image-rendering: pixelated`로 키워서 보여 줍니다.
  - 일기 창의 고르는 칸: 64 × 64 (2배)
  - 식단 목록의 작은 표시: 32 × 32 (1배)
- 밝은 테마와 어두운 테마(크립틱) 양쪽에 올라가므로 **어두운 외곽선**을 두르면 둘 다 잘 보입니다.
- 고르지 않은 스티커는 앱이 알아서 흐리게(회색조) 보여 주므로 따로 그릴 필요 없습니다.

## 적용

1. 이 폴더에 4장을 넣는다.
2. `config.js`의 `sticker_images`를 `true`로 바꾼다.
3. `service-worker.js`의 캐시 이름과 `config.js`의 버전을 올리고 배포한다.

스티커 종류를 늘리거나 문구를 바꾸려면 `js/meal.js`의 `STICKERS`를 고칩니다.
